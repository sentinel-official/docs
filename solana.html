Sentinel dVPN on Solana

The Sentinel dVPN protocol runs on Solana. Its on-chain logic is the dvpn Anchor program, which manages nodes, providers, plans, subscriptions, leases, channels, grants, and payments.

note

Pages in other sections, including dVPN Nodes and dVPN CLI, describe the earlier Sentinel Hub (Cosmos) flow. For the Solana flow, use the pages in this section.

Choose your guide​

  • Node Operators: run a dVPN node and manage it on-chain.
  • Clients: connect to nodes with the sentinel-dvpn CLI and a client daemon.
  • dVPN Program: the program's accounts and instructions.

Components​

BinaryRole
sentinel-dvpnCommand-line tool for wallets, on-chain actions, and client sessions.
sentinel-dvpndDaemon. Runs a node, provider, or client instance. The instance tag sets the role: n<N> for node, p<N> for provider, c<N> for client.

Source code​

Everything in this section is built from the sentinel-solana monorepo:

FolderContents
sentinel-dvpnThe sentinel-dvpn CLI.
sentinel-dvpndThe sentinel-dvpnd daemon.
sentinel-go-sdkGo SDK: VPN protocol integrations (WireGuard, AmneziaWG, OpenVPN, V2Ray, Xray, Hysteria2), node and provider APIs, and the on-chain program client.
sentinel-programsThe dvpn and distributor Anchor programs, their IDLs, and the generated Go client.
sentinel-snapshotChain snapshot tooling.

The CLI and daemon need Go 1.27.3. The programs also need Rust 1.97.1, Anchor 1.2.2, and Solana (Agave) 4.3.2.
